# 📸 Event Media Management Platform

A modern AI-powered Event & Media Management Platform that helps clubs, societies, photographers, and event organizers manage event photos and videos from a centralized location.

🔗 Live Demo: https://event-media-three.vercel.app

---

## 🚀 Problem Statement

Managing event photos and videos across multiple drives, folders, and cloud links becomes difficult as the amount of media grows.

This platform provides a centralized solution for:

- Event-wise media organization
- Smart media discovery
- AI-powered image search
- Facial recognition-based photo finding
- Secure role-based access control
- Social interactions and engagement
